Foodie Flare: Flavor Empire

A complete Acode friendly mobile browser game.

How to play:
1. Open index.html in your browser or Acode preview.
2. Tap the floating flavor icons to earn Flavor Dust.
3. Buy Stand upgrades to increase tap power and automatic production.
4. Unlock Recipes, recruit Mascots, complete Orders, and open new Zones.
5. Your progress autosaves on the device.

How to upload to GitHub Pages:
1. Upload every file and folder exactly as shown.
2. Keep index.html in the root folder.
3. Keep css, js, and assets folders beside index.html.
4. Turn on GitHub Pages for the repository.
